#### Module 1 Repository: Prompting Foundations

This repository contains the working files for Module 1. Use these files throughout the lab to practice prompting techniques and observe how context quality changes Copilot responses.


### Repository File List

The Module 1 repo includes the following files and folders:

- `README.md` - overview of this module and how to use the repo
- `Lab.md` - step-by-step lab instructions
- `Prompts.md` - sample prompt patterns and starter phrasing
- `exercise_solution.md` - reference solution for the exercise
- `db.js` - JavaScript database interaction example used in prompts
- `schema.sql` - SQL schema for the exercise database
- `legacy_v1_backup.sql` - legacy SQL snapshot for comparison and migration-style tasks
- `scratchpad.txt` - free-form area for temporary notes, experiments, and drafts
- `Demo-Exercise-screenshots/` - screenshots used during the demo/exercise walkthrough


For lab instructions, refer to `Lab.md`.
For exercise solutions, refer to `exercise_solution.md`.
